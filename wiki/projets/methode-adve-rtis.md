**Méthode ADVE/RTIS** est une méthode développée au sein de [UPgraders](../organisations/upgraders.md).

## Description

Méthode de stratégie de marque en huit piliers. ADVE (Authenticité, Distinction, Valeur, Engagement) construit le socle identitaire ; RTIS (Risk, Track, Innovation, Stratégie) en déduit le SWOT, la lecture du marché, le champ d'actions et une feuille de route vivante. Elle structure le folio, La Fusée et le programme Shinkiro.

## Les huit piliers

| Pilier | Principe |
| --- | --- |
| **A**uthenticité | On extrait l’ADN, on n’imite pas. |
| **D**istinction | Rupture visuelle immédiate. |
| **V**aleur | Chaque pixel sert un KPI. |
| **E**ngagement | Du spectateur au croyant. |
| **R**isk | Le SWOT déduit de l’ADVE. |
| **T**rack | Étude de marché vs ADVE + Risk. |
| **I**nnovation | Toutes les actions activables. |
| **S**tratégie | Roadmap dynamique. |
